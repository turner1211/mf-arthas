## Navigation isolation

The plugin uses ArthasNav owner `bloodcrypt_delver_v1` with `preempt=false`, refuses the raw shared client, and releases only its own owner. Local input actions require an ownership lease. It does not change global danger zones, BG/questing navigation or other plugins. ArthasNav's owner-aware enhancements and server must already be installed and healthy.

Route/settings data use the dedicated `scripts_data/bloodcrypt_delver` namespace and Markdown files. Received bridge messages are strictly parsed data and never executed. The bridge uses self-whispers, which are sent through WoW chat; this does not make botting undetectable.
