# Assassination Rogue — Valeera Activity Profiles

Project Sylvanas / IZI plugin, version 1.1.55. Built from the Holy Paladin GUI and aura compatibility layer, with new Rogue damage, control, survival, gathering and logging modules.

## Controls

Press **F1** to open or hide the draggable Valeera panel. It uses crimson panels, poison-green switches, two rows of tabs and scrollable settings. The PvE tab selects PvE, Mythic+ or Delve; PvP selects Arena, Battleground or World PvP. Each activity has its own saved damage, opener, cooldown, control and defensive switches. Combat mode always follows the detected activity. Profile buttons choose settings to edit; AUTO returns the editor to the active profile. Automatic kill setup defaults on; no burst request is required. REQUEST BURST remains an optional ten-second override; bleed, immunity and safety conditions still apply.

The master settings live under Core. Auto Stealth, poison preparation, damage, defenses, interrupts, control, prediction and BigWigs support default on. Fishing, looting, skinning, automatic targeting, facing and offensive Vanish default off; enable them on Gathering or Utility as needed. Gathering actions are automatic once enabled. Offensive Vanish remains disabled in PvP and Delves to preserve escape control.

## Separate damage logic

### City training dummies

**City training dummy testing** is enabled by default. Select a confirmed training, target, combat, or PvP dummy and stand within 5 yards while unmounted. Outside real combat, the plugin safely enters Stealth first—even in a detected city—then runs the full opener, sustained rotation, defensive evaluation, and automatic burst cycle. Practice selects automatically by confirmed dummy name: Dungeoneer/cleave uses Mythic+, PvP uses Arena damage practice, raid/generic uses PvE, and explicitly named Delve dummies use Delve. A generic dummy cannot distinguish Arena from Battleground play. Instance context takes priority. Automatic control is suppressed on dummies because training targets cannot reproduce real players, diminishing returns, trinkets, or healer positioning. Nearby positively identified dummies support cleave testing; ordinary city NPCs remain ineligible. Clear the target, leave melee range, mount, pause the plugin, or disable testing to stop practice initiation. Dummy sessions are marked in STATE logs.

## Control and defenses

Kick requires a confirmed interruptible cast, range and line of sight. Kidney is the conditional stop fallback. Stuns use the host's stun diminishing-return query and a conservative local spacing guard. Focus-healer Sap/Blind/Gouge requires readable DR/debuff data and no detected existing CC. Dismantle requires a host-confirmed disarmable attacker threatening an injured friendly target. Unknown DR causes automatic CC to wait for manual control. The plugin protects visible breakable crowd control and immunity; hidden client data can still limit detection.

All modes share a predictive survival layer with mode-aware decisions: a two-second host incoming-damage estimate when available, recent health-loss trend, enemy focus, observed burst buffs, and targeted casts about to land. Prediction takes the larger of forecast/trend rather than adding overlapping estimates; PvP reductions are capped at 18 health percentage points. Feint covers imminent AoE or, with Elusiveness, general pressure. Cloak needs a verified magic school or configured mechanic. Evasion follows close melee/physical pressure. Vial responds to missing health plus predicted danger; emergency PvP Vanish reserves escape use. Each request records its forecast and reason. Prediction is a heuristic, not a guarantee of survival.

BigWigs reads **core.addons.bigwigs** from the supplied Sylvanas host. The native bridge reports seconds. Emphasized unknown timers may trigger Feint **only with Elusiveness**. The plugin never guesses a school from timer wording. Add exact timer labels/keys under your instance name in `ar_encounters.lua` for preemptive AoE Feint or verified magic/physical mechanics. The initial map is empty because exact live timer labels were not supplied. The Logs tab displays active timer status. BigWigs is inactive in PvP; pressure/cast prediction continues. Install and enable BigWigs/LittleWigs in WoW if needed; this package does not install those addons.

## Safe automatic Stealth

Auto Stealth works in every mode while out of combat. It never invokes dismount or mount APIs. It requires a valid living player, a positively clear mount state, confirmed stationary movement and a stable interval. It blocks reported falling, flying, taxi, vehicle, swimming, casting, channeling, skyriding, pending spell requests and active gathering. Vertical movement is checked as an additional fallback. Some host builds lack dedicated falling/taxi/vehicle methods; mount/movement/skyriding/position checks remain active, and missing mount or movement data blocks Stealth. Gathering comes first. This logic does not select enemies or pull them merely because Stealth is enabled.

## Gathering and logs

Fishing uses the existing host profession and bobber helper. It pauses corpse work. Looting uses eligible corpses within 35 yards and the host approach flag. Skinning waits until the corpse has no loot; it can approach within 35 yards using the existing movement helper and harvest at 3.5 yards. Navigation stops on combat, mounting, pause or fishing. Profession, corpse permissions and navigation availability depend on the client.

Logs are written to `scripts_log/assassination_rogue/session.md`, with an in-memory fallback when file writing fails. They include run boundaries, profiles, health, energy, points, prediction, REQUEST/REJECT, SUCCESS/FAILED, timeouts, gathering and control changes. An accepted request means queued by the host; success is recorded only from a confirmed player event/cast. A single pending request, timeouts and increasing failure delays prevent cast spam. The Logs tab copies the path/current run and clears the log.

Crash recovery also mirrors a bounded history to `scripts_data/assassination_rogue/session_history.md`. It is reloaded on plugin startup and can be copied with **COPY SAVED LOG**, so logout, reload and most crashes do not erase the previous session. At most the final unflushed half-second batch can be lost during an abrupt process termination.

## Installation and live sync

Place this folder under `scripts/assassination_rogue`. The GUI is drawn entirely in Lua and requires no image assets. On hosts resolving module names from the scripts root, mirror the `ar_*.lua` modules there; keep `header.lua` and `main.lua` only in the plugin folder. The supplied live sync script performs these copies and verifies SHA-256 hashes. Reload scripts in Sylvanas to load changed code; copying files alone cannot guarantee hot reload by the host.

The workspace is the canonical source. The live watcher validates Lua and behavior checks before copying a changed batch, logs its status, and does not delete unrelated files. Later changes in this chat must be synced and reverified. To stop the watcher, create `outputs/rogue_sync.stop`; restart with the supplied sync script when desired.

The watcher runs as a hidden local process for the current Windows session. It stops on logout/restart; future work in this chat must restart it when absent and verify the live hashes after editing.

Delve and world-PvP priorities are conservative adaptations of class mechanics; the sources do not provide complete automated decision systems for those modes.

Automatic PvP setup pools at least five combo points and 45 energy with bleeds established and a major cooldown ready. It seeks healer control through a selected healer focus, then Kidney Shot on the kill target. Observed healer control can open a burst window directly, including after Kidney on the healer. A confirmed kill-target stun with healer control, low target health, or no visible nearby healer also opens a six-second target-specific burst window. Changing target/profile, protective damage reduction, or critical personal health closes it. Unknown healer visibility is not proof that no healer exists; arena use still needs live testing. Battleground and World PvP also retain their separate health-pressure burst conditions. Emergency predicted magic/melee danger prioritizes Cloak/Evasion before routine Feint.

Shadowstep control/return defaults on in PvP. An enemy healer focus takes priority; otherwise the nearest healer confirmed by role or specialization is chosen. With established bleeds, five points, sufficient energy, safe DR, two readable Step charges and both destinations within 25 yards, it Steps to the healer, confirms Kidney Shot, then Steps back to the original kill target. Failed control attempts request a return; invalid targets, unsafe movement or a seven-second timeout cancel the sequence. This is not terrain navigation and cannot guarantee a return if the enemy moves or breaks line of sight. Every mode uses verified interruptible casts for Kick, with a DR-safe Kidney fallback.

Additional talent handling includes learned spell/charge checks, Instant Poison fallback, Amplifying Poison with Dragon-Tempered Blades, Hemotoxin pressure through Shiv, and System Shock through bleed setup and five-point Envenom. Moving pursuit can use Sprint and ranged Poisoned Knife on an already engaged target; Slice and Dice is maintained only without Cut to the Chase. Passive talents execute in the game and use the host's actual resources, charge counts and cooldowns. This does not constitute complete talent-specific optimization. Shroud, Distract, lockpicking, Pick Pocket, racials, items and Death from Above do not yet have automated policies.

Burst diagnostics now report known spells, cooldowns, usable readiness, Kingsbane combo-point gain and setup blockers in STATE records. Training burst is eligible while a major cooldown is available rather than expiring after six seconds. Reload scripts before testing new code; copying files alone is not evidence of a host reload.

# Starting damage and PvP target swaps (1.0.9)

Left-click selection does not authorize damage. Right-click the selected enemy's world model while it is reported by the host mouseover API. The engagement is cleared on a manual target change or combat ending. Right-clicking elsewhere does not arm damage; unit-frame right-clicks are not guaranteed by this world-object mouseover API. Automatic off-target Sap and predictive defenses remain available before damage is armed.

After a user starts an engagement, PvP can swap to a visible enemy player already in combat, within melee range, at 35% health or lower and at least 20 percentage points below the current target (or when the current target is protected). Controlled, immune and inaccessible enemies are excluded. Swaps wait during kill windows and Step/CC plans and have a five-second cooldown. This is a conservative health/protection policy, not a damage forecast. If the kill target is a healer, off-target DPS CC still requires your explicit focus.
