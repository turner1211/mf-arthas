# Validation

25 Lua runtime scenarios passed using Lupa 2.8 with a mocked Sylvanas host.

Includes all spec selectors and activity detectors, client separation, settings isolation, emergency healing, casting restrictions, no unengaged damage, unsafe dispel protection, interrupt rules, GUI/F1 rendering, and transient reset.

This is offline validation, not an in-game combat test. Actual client spell IDs, talent fingerprints, host texture rendering, and combat behavior still need live validation.
