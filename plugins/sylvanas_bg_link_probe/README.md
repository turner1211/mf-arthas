# Sylvanas BG Link Probe 0.1.1

This is a development diagnostic listener. It observes a narrowly formatted self-whisper addon message and records whether the transport candidate reached Project Sylvanas. It does not queue battlegrounds, supply objective data, control navigation, or perform game actions.

Version 0.1.1 makes registered callbacks inert after reload and protects the local-player identity read. It remains separate from the customer BG Player package.
