Unmodified GNU Unifont 18.0.01, from https://unifoundry.com/pub/unifont/unifont-18.0.01/font-builds/unifont-18.0.01.otf

Copyright belongs to the Unifont contributors named in the font's metadata and the upstream project. Distributed here under the SIL Open Font License 1.1, included in OFL-1.1.txt. This font is separate from the plugin software and retains its original license and name.

The font provides broad Unicode BMP coverage, including the Chinese, Korean, Japanese, Cyrillic and Latin characters used in the bundled catalogs. It is a fallback, not a complete shaping engine: complex-script shaping, right-to-left layout and supplementary-plane coverage are not guaranteed. The helper fetches this versioned asset asynchronously once and caches it in scripts_data; no OS fonts are installed.
